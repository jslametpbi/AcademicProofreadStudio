# Academic Proofread Studio

Professional static GitHub Pages app for academic proofreading, manuscript readiness, tracking, payment confirmation, invoice, receipt, report, and admin management.

## Access
Admin / secure PIN: JS2026

## Deploy
Upload all files in this folder to your GitHub repository root, then enable GitHub Pages from Settings > Pages > Deploy from branch > main > root.

## Payment
This static version uses manual transfer confirmation. Automated gateway verification requires a secure backend.
