# Academic Proofread Studio — V13 Separated Login

## Login structure
- Admin Login is separated from user access.
- User Registration is separated from User Login.
- User must register first before user dashboard login.
- Registered user metadata (name, email, WhatsApp, institution) is integrated into project metadata when creating an order.
- Returning users login with registered email only.
